**KUCHISAKE SHELL** — это стильная интерактивная консольная панель (TUI) с неоновым киберпанк-дизайном, созданная специально для **Pop!_OS (Linux)**. Она объединяет в себе инструменты для повышения продуктивности, трекинга крипты и глубокого мониторинга операционной системы прямо внутри твоего терминала. 

Вся графика, таблицы и анимации построены на базе библиотеки `rich` для максимального визуального кайфа.

---

## ⚡ Основные фичи (5-в-1)

1. ⏱️ **Pomodoro-метод (Фокус-таймер):**
   * Классический цикл: 25 минут хардкора / 5 минут чилла.
   * Визуальный тикающий прогресс-бар в реальном времени.
   * Поддержка умной паузы и звуковой сигнал по окончании сессии.
2. 🖥️ **AI System Health Monitor:**
   * Полная сводка о состоянии твоего ПК (нагрузка CPU, RAM, диски, сеть).
   * Цветная индикация критических нагрузок (зеленый / желтый / красный) — сразу видно, когда система задыхается.
3. 📈 **Crypto & Currency Ticker:**
   * Живой парсинг курсов валют без сторонних платных токенов.
   * Актуальная цена BTC, ETH и курсы USD/EUR в виде аккуратной неоновой таблицы.
4. 📝 **Smart Todo Manager:**
   * Локальный таск-менеджер, интегрированный с таймером Помадоро.
   * Добавление, удаление и отметка выполненных задач (подсвечиваются зеленым).
   * Автосохранение данных в локальный `json`-файл (прогресс не сбросится после перезапуска).
5. 🧹 **Log Cleaner & Temporary Warden:**
   * Безопасный сканер цифрового мусора для Pop!_OS.
   * Находит раздутый системный кэш, логи (`/var/log`) и забитую папку `/tmp`.
   * Показывает, сколько мегабайт можно освободить, и чистит по запросу.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd kuchisake-shell
```

### 2. Установка зависимостей
Для работы утилиты требуются библиотеки работы с системой и графикой:
```bash
pip install -r requirements.txt
```

### 3. Запуск панели
```bash
python3 main.py
```

---

## 🚀 Как запускать одной командой (Глобальный алиас)

Чтобы не прописывать каждый раз путь к папке, добавь короткую команду `kuchisake` в свой терминал:

```bash
echo "alias kuchisake='python3 \$(pwd)/main.py'" >> ~/.bashrc
source ~/.bashrc
```

Теперь просто открой любое окно терминала, введи всего одно слово и панель запустится:
```bash
kuchisake
```
